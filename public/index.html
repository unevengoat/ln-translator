About this library

Storage, backups & updates

The library lives outside the app container, so redeploys and idle sleep never lose data. Saves write immediately; if you edit storage by hand this instance picks it up within ~2 minutes, or press reload. A local workspace uses a separate disk library unless connected to the same durable storage as the live site.
